# Contributing

Thanks for helping improve edualloc.

1. Open an issue or discussion for substantial design changes.
2. Keep pull requests small and include a clear description.
3. Add or update tests for behavior changes.
4. Build with warnings enabled and run `ctest --test-dir build --output-on-failure`.
5. Preserve the project's C99 compatibility and concise, educational style.

Do not add undocumented behavior or make claims about production suitability. By contributing, you agree that your work may be distributed under the MIT License.
